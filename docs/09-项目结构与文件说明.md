## 2. 哪些东西**不在**仓库里（以及为什么）

| 不在仓库 | 原因 | 怎么得到 |
|---|---|---|
| `tools/arduino-cli`（约 30MB） | 二进制，随平台变化 | `scripts/setup-toolchain.sh` 下载 |
| `arduino-data/`（约 1GB ESP32 核心） | 体积过大 | 同上，一条命令装 |
| `firmware/build/`（编译产物） | 可重现 | `./scripts/build.sh` |
| `firmware-backup/original-firmware-4MB.bin` | 4MB 二进制，且是卖家的固件 | `./scripts/ob.sh backup`（**建议第一次就做**） |
| OpenBot 上游完整源码（含 iOS/训练脚本） | 上游有自己的仓库 | `git clone --depth 1 https://github.com/ob-f/OpenBot` |

**为什么不把整个 OpenBot 塞进来**：它会带来 200MB+ 的历史和持续的上游更新冲突。我们只保留"自己改过的那一个文件"，其余按上游引用。这也让"我到底改了什么"一眼可见。

## 3. 一次控制指令走过哪些代码

以"iPhone 推摇杆前进"为例：

```
① iPhone App（上游代码，不在本仓库）
   摇杆 y 轴 → 目标速度 v（-1.0 … 1.0）
        ↓
② BLE 写入控制特征值
   帧：0x0F + 左右轮速度（各 2 字节，-255…255）
        ↓
③ 固件 openbot.ino :: parsePacket()
   取出左右轮速度 → ctrl_left / ctrl_right
        ↓
④ 固件 :: setMotorSpeed(ctrl_left, ctrl_right)
   · 应用死区补偿：ctrl_min = 255 × VOLTAGE_MIN / VOLTAGE_MAX ≈ 191
   · 换算成 LEDC PWM 占空比（5 kHz）
        ↓
⑤ 固件 :: setLeftMotor() / setRightMotor()
   左：PIN_PWM_LF1(19)=PWM, PIN_PWM_LF2(21)=0    ← 正转
   右：PIN_PWM_RF1(32)=PWM, PIN_PWM_RF2(33)=0
        ↓
⑥ MX1508 → TT 马达 × 4（每侧两个并联）
```

**停止时**：两脚同时置高（刹车）或同时置低（滑行，由 `COAST_MODE` 决定）。
**断线保护**：固件有看门狗，超过设定时间没收到指令就自动停车——这是它比卖家固件安全的地方，卖家版断连后车会保持最后指令继续跑。

## 4. `ob.sh` 的七个命令

| 命令 | 干什么 | 输出里该看什么 |
|---|---|---|
| `./scripts/ob.sh status` | 一屏看全：串口、固件大小、备份、芯片、引脚表 | 串口是否有 ✅；固件占用率 |
| `./scripts/ob.sh build` | 编译 | `Sketch uses ... (86%)` |
| `./scripts/ob.sh flash` | 烧录（自动 230400） | `Hash of data verified.` |
| `./scripts/ob.sh monitor` | 串口实时日志（115200） | 启动横幅、状态行 |
| `./scripts/ob.sh backup` | 备份整片 4MB | 约 3 分钟，产出 4.0MB 文件 |
| `./scripts/ob.sh restore` | 烧回备份（卖家原厂） | 整片 `0x0` 写入 |
| `./scripts/ob.sh pinmap` | 打印引脚对照表 | 对照 [02](02-引脚与接线.md) |

端口默认 `/dev/cu.usbserial-10`，可用环境变量覆盖：

```bash
OB_PORT=/dev/cu.usbserial-XXXX ./scripts/ob.sh status
```

## 5. 环境变量（脚本内部已处理，手动跑时要带上）

```bash
export ARDUINO_DIRECTORIES_DATA="$PWD/arduino-data"
export ARDUINO_DIRECTORIES_DOWNLOADS="$PWD/arduino-dl"
export ARDUINO_DIRECTORIES_USER="$PWD/arduino-user"
```

**为什么必须隔离**：arduino-cli 默认把 1GB 核心装到 `~/Library/Arduino15`，会污染全局、和已有 Arduino IDE 冲突。项目内隔离 = 删目录即卸载。

## 6. 两个 HTML 页面

| 文件 | 用途 | 怎么看 |
|---|---|---|
| `web/OpenBot小车上手计划.html` | 四周节奏、采购清单、坑清单、验收标准 | 双击打开；也可发到手机微信里打开 |
| `web/OpenBot项目控制台.html` | 硬件核对结果、引脚表、带时间戳的操作流水、固件改动、文件路径 | 同上 |

它们不是"文档的另一种格式"，而是**执行时对着一张看的手册**——比如装电池那天，打开控制台页面照着念就行。
