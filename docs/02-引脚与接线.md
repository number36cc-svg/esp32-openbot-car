# 02 · 引脚与接线

> 本车的全部接线信息都在这一页。它来自**卖家固件源码里的 `#define`**，不是商品页文案——这是唯一可靠的来源。

## 1. 引脚对照表

| 功能 | ESP32 GPIO | 说明 |
|---|---|---|
| 左电机 IN1 | **GPIO 19** | 左前 + 左后两个马达并联 |
| 左电机 IN2 | **GPIO 21** | 同上 |
| 右电机 IN1 | **GPIO 32** | 右前 + 右后两个马达并联 |
| 右电机 IN2 | **GPIO 33** | 同上 |
| 电机驱动电源 | 板载 6V（升压后） | 不经过 ESP32 |
| ESP32 供电 | 板载 3.3V（降压后） | 不走 USB 时 |
| 电量检测 | **无** | 板上没有分压电路 → `HAS_VOLTAGE_DIVIDER 0` |
| 编码器 / 超声波 / LED / OLED / 摄像头 | **都没有** | 对应宏全部设 0 |

## 2. MX1508 的控制语义（关键）

MX1508 是双 H 桥，每个电机用两根线控制，**没有使能脚**（和 L298N 的 ENA/ENB 不同）：

| IN1 | IN2 | 结果 |
|---|---|---|
| 高 | 低 | 正转（满速） |
| 低 | 高 | 反转（满速） |
| **高** | **高** | **刹车**（短路制动） |
| 低 | 低 | 滑行（自由停转） |

要调速就对该为高的那一路打 PWM：

```
正转：IN1 = PWM(duty),  IN2 = 0
反转：IN1 = 0,          IN2 = PWM(duty)
刹车：IN1 = 1,          IN2 = 1
滑行：IN1 = 0,          IN2 = 0
```

**为什么这和 OpenBot 天生兼容**：OpenBot 的电机抽象就是"每侧两个引脚，一个置高一个给 PWM，停止时两个都置高"——正好等于 MX1508 的刹车语义。所以适配时**不需要改驱动逻辑，只改引脚号**。

## 3. ⚠️ 启动死区：占空比 < 75% 电机不转

这是本车最容易被误判为"固件写坏了"的点。卖家固件里写死了 `MOTO_MIN_PWM 75`——占空比低于 75%，电机纹丝不动。

**OpenBot 固件里对应的补偿机制**：

```c
// 最小控制量 ctrl_min = 255 * VOLTAGE_MIN / VOLTAGE_MAX
#define VOLTAGE_MAX 6.0f
#define VOLTAGE_MIN 4.5f   // 4.5/6.0 = 75%
```

原理：OpenBot 把"用户给的速度值"换算成"电压"，再换算成 PWM 占空比。把 `VOLTAGE_MIN` 设成 75% × `VOLTAGE_MAX`，等于告诉固件"低于 75% 的输出等同于没有"——摇杆一推就有反应，不会出现"推一半车不动、推到底猛窜"。

> 换车的话：如果你的车也是"低速不转、某点突然起转"，就按 `实测起转占空比` 设 `VOLTAGE_MIN`。
> 例：实测 60% 起转 → `VOLTAGE_MIN = 0.6 × VOLTAGE_MAX`。

## 4. 板载电源链路（为什么不用买降压模块）

```
4 × 5 号电池（4.8-5.6V）
   ├─► 升压电路 → 6V ─► MX1508 VCC ─► 电机
   └─► 降压芯片 → 3.3V ─► ESP32 3V3
```

关键结论：

- **ESP32 不需要额外降压模块**（很多教程会要你买 MP1584，这车不用）
- **不能用 3S 18650**：MX1508 上限约 9.6V，且板载升压固定输出 6V，电机档位是定死的
- **USB 与电池不能同时供电**：USB 5V 和板载 3.3V 会打架 → 烧录时关电池开关（见 [03-刷机指南](03-刷机指南.md)）

## 5. 没有图纸时，怎么自己把引脚量出来

如果卖家不给源码（本车给了，但下台车可能不给），20 分钟能自己搞定：

1. **找电源**：万用表直流档，黑表笔接电池负极，红表笔点驱动板上的 VCC 脚——读数为 6V 左右说明是电机电源
2. **找控制线**：ESP32 上电但不接电池，用万用表通断档（或蜂鸣档），一端点 MX1508 的 IN 脚，另一端逐个点 ESP32 的 GPIO——响的就是连接关系
3. **验证左右**：给某一组 IN 手动加高电平（或用 `digitalWrite` 写个小程序），看哪两个轮子转 → 那就是同一侧
4. **验证方向**：正转时轮子应朝车头方向滚；反了就在固件里对调该侧两个引脚号

## 6. 接线自检清单（上电前必看）

- [ ] 所有白色 JST 插头插到底（听到"咔"）
- [ ] 焊点没有发黑、虚焊、连锡
- [ ] 电池盒正负极没接反（板上有丝印 `+` / `-`）
- [ ] 车轮悬空后再开电源（第一次上电务必架空）
- [ ] USB 已拔出（或电池开关已关）
- [ ] 电池是**镍氢 1.2V × 4**，不是碱性、不是 18650
