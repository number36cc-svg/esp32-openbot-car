⚠️ 开工前必须知道的三个硬约束

1. 主控必须是 ESP32，不是 Arduino Nano。
OpenBot 的 iOS App 只支持蓝牙 BLE 连接，不支持 USB 串口（安卓才走 USB-OTG）。而 BLE 只有 ESP32 板子支持，固件里对应 DIY_ESP32 配置。买 Nano = 白买。
2. iOS App 不在 App Store，要自己编译安装。
需要 Xcode + CocoaPods + 自建 Firebase 项目（补 GoogleService-Info.plist，App 用谷歌登录存项目）。免费开发者证书 7 天过期，到期要重新连 Mac 编译一次；付费开发者账号（¥688/年）可一年一签。
3. iPhone 16 是 199g 的配重。
压在 3D 打印顶板上重心偏高，急转弯容易翻。对策：电池放最底层、轮距加宽、速度先用 Slow 档。

四周节奏（按你在保定过周末来排）

0
Week 0（工作日，线上）· 采购 + 环境预热
下单全部配件，寄到保定 | 我这周帮你把 Xcode / ESP32 工具链 / OpenBot 仓库备好
  • 收货后先只验货不焊线：ESP32 插 USB 看能不能被 Mac 识别（ls /dev/cu.* 能看到就正常）
  • Arduino IDE 装 ESP32 开发板支持 + 刷一个 Blink 例子验证烧录通路
  • 装 PinChangeInterrupt 库（码盘/超声要用）
1
Week 1 · 机械 + 通电，目标：轮子会转
耗时 3-4 小时 | 验收：手机 App 或简单串口命令能让四个轮子前后转
  • 装手机支架、垫镜头俯角（整车电源和底盘出厂已装好，主要是加装手机位）
  • 整车到手先核对：MX1508 电机供电接的是电池 7.4V（不是 3.3V），ESP32 供电走降压模块 5V
  • 按卖家例程的引脚表改 OpenBot 固件宏（DIY_ESP32 段），我提前改好，到手即烧
  • ⚠️ 先架空车轮（垫起来让轮子悬空）再上电测试，避免飞车
2
Week 2 · 蓝牙连通 + iOS App 上身，目标：手机遥控
耗时 4-6 小时（大头在 Xcode 签名和 Firebase）| 验收：App 里能看到电量/速度，能开能停能转向
  • Mac 上 clone 仓库 → pod install → 用自己的 Apple ID 签名 → 装机
  • 建一个 Firebase 项目，下载 GoogleService-Info.plist 塞进工程（不做这步 App 起不来）
  • 手机开开发者模式，信任证书；记住 7 天后失效这件事
  • BLE 配对：App 里出现 OpenBot 设备 → 连接 → Free Roam 页控制
  • 接一个蓝牙手柄（PS4/Xbox）体验更好，键盘控制会手忙脚乱
3
Week 3 · 采集数据 + 人物跟随，目标：它会看你
耗时 3 小时 | 验收：车能锁定人并保持 1-2 米距离跟走
  • 先用 App 的 Object Tracking + 预训练模型（COCO 80 类里选 person）
  • 调整摄像头俯角（下倾 15-30°，让前方 1-3 米进画面），这是跟随能不能成功的关键
  • 地上贴胶带划一条测试路线，重复跑，记录成功率
4
Week 4 · 训练自己的驾驶策略，目标：端到端自动驾驶
耗时 1 个周末 + 训练时间 | 验收：跑完一圈不撞、不卡
  • Data Collection 页录 20-30 圈（每圈 1-2 分钟，不同光照/角度各录几组）
  • 用仓库 policy/ 的训练脚本在 Mac 上训练（M 系列芯片够用），导出 TFLite
  • 模型传进 App（支持自定义 TFLite，可选 CPU/GPU/Neural Engine）→ Autopilot 页跑
  • 这里是真正的具身智能：数据 → 训练 → 部署 → 失败分析 → 再采数据

坑清单（照这个避开 90% 的翻车）

坑后果对策
买了 Arduino NanoiOS 连不上，纯废只买 ESP32（WROOM-32 DevKit）
整车无码盘（测速）App 里速度显示为 0、无里程计；不影响遥控/跟随/数据采集/策略训练固件先关掉（HAS_SPEED_SENSORS 0）；以后想上里程计再买带霍尔编码器的 TT 马达 ×4（~¥80）替换，信号线接 ESP32 空闲 GPIO
刷固件时电池没关USB 5V 与电池 3.3V 同时供电，轻则烧录失败重则伤板铁律：插 USB = 关电池，拔 USB = 开电池

验收 checklist

  • ESP32 能被 Mac 识别，能烧录 Blink
  • 四个轮子方向正确（架空测试）
  • App 能通过 BLE 连上，能看到电量与测速数据
  • 手柄遥控正常，急停有效
  • 人物跟随能稳定跟 30 秒以上
  • 数据采集能正常落盘，导出到 Mac 能打开
  • 训练出的模型在车上能跑完一圈不撞

跑通之后的进阶方向

  • 相机升级：把闲置的 Osmo X3 云台架上车，做三轴稳定的“机器人眼睛”（独立供电，不占车电）
  • 换脑：树莓派/Jetson 走 robot/linux 分支，摆脱手机，跑更大模型
  • 自定义任务：把“找红色物体”“巡线”“门口巡逻”写成自己的策略
  • 多机协同：再买一套底盘，两台车互相避让（App 支持 WebRTC 远程控制）
